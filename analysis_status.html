Stage 01

Signal → ERSP

Turn raw clinical recordings (three cohorts, three conditions) into cleaned, trial‑locked event‑related spectral perturbation (ERSP) cubes — the shared substrate every later stage consumes — plus micro‑electrode spike detection.

Method — notebook 140 (the ERSP producer)

  • Load & clean. Format‑agnostic (TRC/EDF/H5); drop aux; white‑matter re‑reference (subtract mean of ≥3 good WM contacts, macros only).
  • Adaptive mains notch. 50 Hz + harmonics, but a harmonic is notched only if its spectral peak z ≥ 3 over local background; zero‑phase.
  • Trial QC. Hard filters (min stim 0.5 s, max post 10 s) then IQR outlier trim (k=1.5).
  • ERSP. Resample 1 kHz → STFT (Hann, nperseg=128, nfft=256, ~85% overlap) → dB. Time‑warped "TN": baseline/stim/post onto a 300‑bin axis, stimulus and response each 50% (bin 150 = GO‑cue). Baseline window (−0.6, −0.1) s; display ±6 dB, 0–500 Hz.
  • High‑gamma. 70–150 Hz Butterworth → Hilbert envelope → 25 ms smoothing → baseline z.
  • Output. Per‑channel ERSP .npy (in 04_ersp_LM_RAWONLY/…/ERSP_matrix/) — the cube 02/03/04 read.

Stage 02

Clustering — functional response types

Group the trial‑averaged ERSPs into data‑driven response types. Every representation clusters the same 2102 high‑activity samples; only the feature space changes. The high‑gamma track is the de‑facto canonical result.

Method

  • Representations (one orchestrator). raw 129×300 · downsampled 15‑band×30 · minus101 (−1/0/+1) · HG line (70–150 Hz mean, 1‑D×300). Each → K‑Means + Ward, K‑sweep, best K by silhouette.
  • Why HG. Cleanest separation (silhouette HG 0.152 > downsampled 0.083 > raw 0.045); optimum sits at low K, so HG uses K∈[6..20].
  • Validation. Consensus stability (50 restarts → co‑clustering + per‑cluster Jaccard), gap statistic, anatomical purity (Desikan‑Killiany).
  • Ranking. Dissolve clusters that fail to bridge both cohorts (EL↔PAT); composite = 4·cross‑patient + 3·stability + 2·condition + 1·spatial‑compactness.
  • Recon. Each cluster's electrodes rendered on the fsaverage pial surface.

Stage 03

Decoding — what an electrode's response tells us

Two supervised questions on the same ERSPs: can we decode the stimulus condition (audio / picture / reading) from a single electrode, and can we decode which Yeo network an electrode sits in from its 3‑condition profile? Everything is generalisation to a new patient.

Method

  • Classifiers. Multinomial logistic regression + random forest, both balanced.
  • Validation. Nested GroupKFold by patient (5 outer test patients, 3 inner for tuning) — no patient in train and test.
  • Metric. Balanced accuracy vs chance, with a bootstrap 95% CI resampled over patients; significance from a grouped label‑permutation null (N=200).
  • Feature variants. {full 15‑band, HG line} × {300, 30 time bins} × {continuous, row‑normalised} — matched pairs that isolate frequency content, time resolution, and amplitude vs pattern.

Stage 04

Pooling — a‑priori functional roles

The confirmatory counterpart to clustering: instead of letting the data find groups, we draw a‑priori role templates from language theory (auditory input, visual, premotor planning, phonological encoding, speech‑motor, …) and ask which electrodes express each, and where. Full detail in METHODOLOGY.md.

Method

  • Concatenate the 3 conditions per contact → one [audio | picture | reading] map.
  • Role templates = conjunctions of boxes (time‑% × Hz × sign) with a per‑role dB threshold + fraction gate; three layers (functional roles / spectral tags / umbrellas); multi‑label with a most‑specific "primary".
  • Matching grid = 15‑band × 30‑time, kept bit‑identical to the poolv2 web designer.
  • HGA timeseries (70–150 Hz) computed at full resolution for smooth curves; onset per condition.
  • Anatomy = Yeo networks + Neurosynth meta‑analytic regions (fsaverage → MNI152 z‑maps), rendered on fsaverage.
