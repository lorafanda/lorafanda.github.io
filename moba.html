About this view

MOBA is an interactive 3D dashboard for clustering results. Pick a run from the dropdown above to see all clustered iEEG contacts plotted on a translucent fsaverage cortex, with synced ERSP thumbnails on the right and live metrics below.

Brain

Each sphere is one (patient × electrode × condition) sample, positioned at its MNI coordinate on FreeSurfer's fsaverage. Drag to rotate, scroll to zoom, right-drag to pan. Hover for a tooltip; click to highlight the sample's thumbnail on the right. Color encodes whichever attribute is selected in the Color by filter (Cluster / Patient / Condition).

ERSP samples

Each thumbnail is one trial-averaged ERSP image (04_ersp_LM_RAWONLY/<patient>/LM/ERSP_clean), displayed in dB with a symmetric color range of −6 to +6. Caption is the source PNG filename. The badge in the top-right of each thumbnail is the per-sample silhouette: green if positive (sample fits its assigned cluster better than any other), red if negative (sample is closer to a different cluster).

Filters

Toggling cluster/patient/condition chips updates the brain, the samples grid, and the metrics simultaneously. High-sil only hides any sample with silhouette ≤ 0 — useful for showing the confident core of each cluster.

Metrics (live)

The summary line counts the currently visible samples (post-filter). The two stacked bars show the patient and condition makeup of that selection — a cluster with high patient diversity is a cross-patient pattern; a cluster dominated by one patient is a likely artifact.
