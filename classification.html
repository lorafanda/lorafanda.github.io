How to read this page

Accuracy
Fraction of test samples classified into the correct class. Compare against the chance baseline (1 / n_classes) — accuracy near chance means the classifier learned nothing.
F1 (macro)
Harmonic mean of precision and recall, averaged equally across classes (so rare classes count as much as common ones). Robust to class imbalance.
ROC-AUC (macro)
Area under the ROC curve, one-vs-rest, averaged across classes. 0.5 = chance, 1.0 = perfect ranking. Measures how well scores separate classes regardless of threshold.
Precision
Of the samples predicted as this class, what fraction actually are. High precision = few false positives.
Recall (sensitivity)
Of the samples that truly are this class, what fraction were found. High recall = few false negatives.
Support
Number of true test samples in this class. Small support → noisy per-class metrics.
Confusion matrix
Rows = true class, columns = predicted. Diagonal = correct. A bright off-diagonal cell shows a systematic confusion between two classes.
Chance baseline
Accuracy a random classifier would get: 1 / n_classes (e.g. 33% for 3 classes, 14% for 7). Always read accuracy relative to this.
Yeo network number
The chip before each Yeo class name is its canonical network index (7-network: 1=Visual … 7=Default; 17-network: 1–17). Lets you cross-reference the standard atlas.
Feature importance
How much each input feature contributed to the model's decisions (e.g. RF impurity decrease, or |coef| for linear models). Tells you which frequency band × time bin drives the classification.
GroupKFold
Cross-validation where a whole patient is held out together — no patient spans train and test. Prevents the model from "memorising" a patient and inflating accuracy.
